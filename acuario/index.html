Control de experiencia

● OLED: negro transparente
Cómo jugar: mueve las manos para que los peces se aparten. Junta pulgar e índice para soltar comida. Si el reconocimiento de manos falla, la app usa movimiento general como alternativa. Toca el acuario para dar comida. Teclas H controles · F pantalla completa.

🐠 Acuario interactivo

Conecta una webcam USB al computador del OLED. Los peces reaccionarán a tus manos y se acercarán a la comida que sueltes.

Este modo OLED utiliza fondo negro para dejar visible lo que está detrás de la pantalla. También puedes activar un fondo azul para mostrar la experiencia en un monitor normal.

La webcam necesita permiso del navegador. El video se analiza en este dispositivo: no lo grabamos ni lo enviamos. El modelo de manos se descarga de un proveedor externo al iniciarse.
